# لوحة تحكم إدارة المشاريع الإبداعية

منصة مركزية لإدارة المشاريع الإبداعية والمهام والملفات والتعاون الجماعي، مصممة خصيصًا للوكالات الإبداعية ومديري المشاريع والمصممين.

## المميزات

- إدارة العملاء والمشاريع
- إدارة المهام مع تتبع المراجعات
- إدارة الملفات المركزية (باستخدام Supabase)
- إدارة حسابات التواصل الاجتماعي بطريقة آمنة (مع تشفير AES-256)
- تحكم بالصلاحيات على أساس الأدوار
- لوحة إحصائيات تفصيلية
- إشعارات فورية
- دعم اللغة العربية والإنجليزية مع دعم RTL

## التقنيات المستخدمة

- **الواجهة الأمامية**: Next.js 14, Tailwind CSS, IBM Plex Arabic
- **الواجهة الخلفية**: Supabase (قاعدة البيانات والملفات)
- **الأمان**: تشفير AES-256, HTTPS, RBAC

## متطلبات التشغيل

- Node.js v16+
- حساب [Supabase](https://supabase.com)

## إعداد المشروع

### 1. تثبيت الاعتماديات

```bash
npm install
```

### 2. إعداد متغيرات البيئة

قم بنسخ ملف `.env.local.example` إلى `.env.local` وقم بتعديل القيم:

```bash
cp .env.local.example .env.local
```

قم بتعديل القيم في ملف `.env.local`:
- أضف عنوان URL الخاص بـ Supabase ومفاتيح API
- قم بتعيين مفتاح تشفير قوي

### 3. تشغيل المشروع للتطوير

```bash
npm run dev
```

سيتم تشغيل المشروع على المنفذ 3000 (http://localhost:3000).

### 4. بناء المشروع للإنتاج

```bash
npm run build
npm run start
```

## الهيكل العام للمشروع

```
/src
  /app                # مكونات الصفحات (Next.js App Router)
  /components         # المكونات المشتركة
  /lib                # الوظائف المساعدة والأدوات
  /styles             # ملفات التنسيق العامة
/public              # الملفات الثابتة
```
